# Главная папка — картотека человека

Как у нас на сервере: память дела не теряется между чатами, потому что у каждого дела своя страница, а у каждой вещи — своя полка. Чат закончился — знание осталось в папке.

## Полки

```
<Главная папка>/
  Указатель.md          ← читать первым: что где лежит, строка на полку, дата изменения
  Проекты/
    <Проект>/           ← файлы проекта (документы, таблицы, фото, код)
      ПРОЕКТ.md         ← цель · сейчас (что сделано, что дальше) · решения с причиной · люди
      Заметки/ГГГГ-ММ-ДД-<тема>.md  ← итог значимого разговора, если он пригодится потом
  Люди/<Имя Фамилия>.md ← кто, откуда, как связаться, договорённости, важное личное
  Темы/<Тема>.md        ← знания, справки, инструкции вне проекта
  Входящие/             ← временно, пока полка не ясна; разбирать при случае
```

Папки `Проекты/…` программа сама показывает слева отдельными проектами — человек открывает чат прямо в нужном.

## Куда класть — решение за 10 секунд

1. Прочитай `Указатель.md`. Есть подходящая полка — дополни её (новый раздел, строка с датой), **не заводи дубль**. Имя похоже, но не то же («Отчёт продаж» и «Продажи — отчёт») — это одна полка.
2. Это **проект**? Да, если у дела свои файлы или к нему возвращаются второй раз. → `Проекты/<Название>/`. Нет — разовый вопрос: знание → `Темы/`, ерунда → никуда.
3. Это **о человеке**? → `Люди/<Имя Фамилия>.md` (один человек — один файл; сначала поищи по имени и фамилии, по почте и телефону).
4. Не понятно → `Входящие/` и строка в конце ответа «положил во Входящие, скажите, к чему отнести».

## Как писать

- Коротко и по делу: факт, дата, откуда. Решение — с причиной («выбрали X, потому что Y»).
- Обновляй, а не копи: устаревшее исправь на месте, историю — строкой «было → стало, дата».
- Личное о людях — только то, что человек рассказал сам и что пригодится ему же. Пароли, ключи, номера карт — никогда.
- Названия папок и файлов — человеческие, по-русски, без дат в названии проекта.

## Когда

- **В начале** разговора — `Указатель.md` и `ПРОЕКТ.md` текущей папки (если есть). Пересказывать их человеку не нужно — просто работай с учётом.
- **По ходу** — когда узнал важное надолго (решение, контакт, договорённость), запиши сразу, а не в конце.
- **В конце** значимой работы — «сейчас» в `ПРОЕКТ.md` и строка в `Указатель.md`, если появилась новая полка. В ответе одной строкой: где сохранил.

## Когда НЕ

- Пустяки и одноразовые вычисления — не сохранять.
- Чат про программирование внутри репозитория с собственными правилами (`CLAUDE.md`, `agent.md`) — следовать правилам репозитория, картотеку не засорять.
- Главной папки нет — не выдумывать её; одной строкой предложить выбрать: «Настройки → Папки».
