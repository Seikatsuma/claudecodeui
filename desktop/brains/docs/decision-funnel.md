# Воронка решений — «испытательный отбор с заземлением»

Применяется к ЛЮБОМУ выбору; ширина и строгость масштабируются диспетчером. «Чьё решение» проверяется ДО воронки (см. `PROTOCOLS.md`), но решения пользователя тоже идут ЧЕРЕЗ неё: модель готовит «вариант + почему», окончательное слово — за пользователем; для денег и необратимого — явное «да» текстом, молчание не согласие.

Принцип всех рубежей: **рубеж существует, только если его проверяет не тот, кто его проходит, и не текстом — а фактом, скриптом, отдельным контекстом или другой моделью.** Текстовая строгость усыпляет сильнее её отсутствия.

## Этап 0. Диспетчер (30 секунд, всегда)

Четыре флага да/нет — не «ощущение сложности»:
- **Д** — деньги, договор, закупка. Мелкие суммы и откат дешевле часа флаг не поднимают (порог задаёт пользователь).
- **Н** — необратимость: откат дороже часа, «дверь в одну сторону».
- **Л** — люди, прод, чужое: результат увидит человек, затронута чужая система, рабочая среда, общие ресурсы (порты, память, процессор, службы).
- **Нов** — нет проверенного образца в памяти и уроках.

| Флаги | Уровень | Ширина | Строгость |
|---|---|---|---|
| 0 | L0 | 1 | прямое действие |
| только Нов | L1 | до 3 | в уме + строка самопроверки (главное допущение → что если неверно) |
| один из Д/Н/Л | L2 | до 5 | кратко за/против + мини-самопроверка |
| два флага | L3 | до 10 | карточки, рубрика, независимый помощник, скептик |
| Н+Д, закупка, подрядчик, архитектура, стратегия | L4 | до 15 | полная воронка + премортем + другая модель |

Правила поверх:
- **Предусловие уровня** — фраза «самое дорогое, что сломается, если решение неверно — …». Без неё уровень не присвоен.
- **Жёсткие минимумы** против самозанижения: деньги наружу, изменение прода, необратимая операция над данными, касание чужих систем → минимум L3; закупки, подрядчик, архитектура → L4.
- **Эталоны:** продукт для заказчика = L4; текст кнопки в работающем сервисе = L2; имя переменной = L0.
- **Уровень называется одной строкой всегда, даже L0** («L3: прод+деньги») — занижение, самая дорогая ошибка, должно быть видно.
- **Инцидент:** пожар в рабочей среде или известная инструкция → действие немедленно (распознал образец → действие → план отката), полный разбор — постфактум.
- **Андон:** по ходу всплыли деньги, прод или необратимость — уровень вверх немедленно. Понижение по найденному образцу — только при совпадении ТРЕБОВАНИЙ, а не темы (та же «расшифровка речи», но другие требования к точности — это другой случай), с записью причины.

## Этап 1. Постановка задачи (L2+)

2–3 «зачем» вверх, пока не упрёшься в настоящую цель. Сформулировать наблюдаемый критерий успеха ПОСЛЕ внедрения. **Кандидат №0 «не делать / переопределить задачу» входит в каждый пул** — воронка не должна полировать ответ на неверный вопрос.
Рубеж: критерий успеха назван; цепочка «зачем» упирается в цель.

## Этап 2. Карта фактов и заземление

- Несущие утверждения размечаются **[F] / [H]**. [F] действителен только со способом проверки (команда, файл, строка). Сниппет из поиска — [H]. Содержимое памяти — [H] до проверки.
- **Снимок ≠ закономерность:** разовый замер — не правило; приоритет у первоисточника истины.
- Факт, который не добыть чтением (качество, конверсия), — явное решение: «меряем об эталон» или «принимаем гипотезу с записанной ценой риска».
- Проверки только на чтение — свободно; изменяющие — только через красные линии `CLAUDE.md`.
- Даже в мелком выборе несущее проверяемое допущение проверяется инструментом: один поиск дешевле и точнее пяти вариантов. Самая высокая отдача на токен во всём методе.

Рубеж: ни одного несущего [H] без проверки или записанного риска; каждый отсев по факту цитирует факт.

## Этап 3. Варианты покрытием

- Сначала карта принципиально разных **механизмов** решения, потом по представителю на механизм. Два варианта без фразы «чем механизм А отличается от Б» — дубль, сливаются.
- Числа 3/5/10/15 — **потолки при насыщении, не квоты**: два кандидата подряд без нового механизма → стоп. Добивание квоты перекрасками фабрикует псевдоварианты.
- L3–4: генераторы независимы, друг друга не читают; разнообразие навязывается **инверсионными затравками** («реши без покупки», «реши удалением», «только имеющимися инструментами»). На L4 один из генераторов — другая модель: копии одной модели декоррелируют слабо.
- Генераторы себе баллы не ставят — оценивает только судья.

## Этап 4. Рубрика и карточки

- **Рубрика ДО чтения вариантов:** критерии, веса заранее, письменные якоря «что такое 3/7/9» по каждому критерию. Есть класс **вето-критериев** — они не выбрасываются ни при каком разбросе.
- Первый срез — **сито ОБЯЗАТЕЛЬНО/ЖЕЛАТЕЛЬНО**: нарушение жёсткого ограничения или противоречие проверенному факту. Обязательное условие, добавленное после начала генерации, помечается «задним числом» и не может быть единственной причиной отсева.
- Карточка: механизм одной фразой; **не меньше 5 пунктов «что хорошо»**; «против»; допущения; **оценки 1–10 по якорям, каждая с письменным «почему именно столько»**. Оценивать по одному критерию поперёк всех вариантов, а не вариант целиком.
- Поверх баллов: **слепые парные сравнения в двух порядках** для топ-3. Честная ничья легальна с письменным «почему равны».
- Критерий, который не различает варианты (разброс ≤2 у всех), — вес 0 и замена, кроме вето-критериев.

## Этап 5. Срезы со сборкой (15 → 10 → 5 → 3 → 1; L3: 10 → 4 → 1; L2 — мини-сборка)

L2 (до 5 вариантов): после выбора лучшего — проход по остальным: лучшую мысль каждого вобрать в финалиста или отклонить с причиной, 2–3 строки. **Сборка лучшего из всех в один действует на всех уровнях от L2.**

На каждом срезе:
1. **Реестр сирот:** сильные свойства отсечённых, не покрытые выжившими, выписываются; каждый выживший усваивает их или отклоняет с причиной.
2. **Гибрид** из непокрытых преимуществ входит НОВОЙ карточкой через полную рубрику и заземление — непроверенный «франкенштейн» не побеждает.
3. **Перевзвешивание** — только по письменному факт-триггеру («увидели в варианте 7, что…») + **проверка новых весов на отсеянных с правом воскрешения** — иначе пересборка превращается в рационализацию.
4. Срез ничего не изменил → этап схлопывается со следующим (защита от ритуала).

Финалист меряется об **задачу**: чек-лист жёстких ограничений этапа 1, каждое с доказательством. «Лучший среди остальных» ≠ «лучший для задачи».

## Этап 6. Самопроверка (обязательный рубеж, L2+)

L2 — три строки: главное допущение → «что если неверно» → контрпример с превращением в проверку.
L3–4 — **скептик в свежем контексте**: видит задачу, финалиста, карту фактов и источники; НЕ видит журнал воронки (иначе наследует рамку и смягчается). На L4 скептик — другая модель.

Операции:
1. Выписать **все допущения** решения списком.
2. По каждому — **«что произойдёт, если оно неверно»** и насколько больно. Проверяемое сейчас → доразведка (назад на этап 2); непроверяемое → kill-критерий.
3. **Контрпример из трёх частей:** конкретная ситуация + наблюдаемый сигнал + что именно ломается. Засчитывается ТОЛЬКО превращением в kill-критерий или проверку; «в принципе может не сработать» — не контрпример. Не находится → формулировка решения слишком общая → сузить и ещё проход; два пустых прохода → назад к постановке или вопрос пользователю.
4. L4 дополнительно: **премортем** («через три месяца решение провалилось — самая вероятная причина») → ещё kill-критерии.

Дебаты нескольких агентов в метод сознательно не включены: прирост скромный, цена высокая — ритуал строгости.

## Этап 7. Фиксация и петля

- Выход: решение + почему + факты и допущения + **kill-критерии** (сигнал + порог + где смотреть + кто и когда) + дата пересмотра. L3–4 — одностраничник в `decisions/ГГГГ-ММ-ДД-тема.md`; L2 — в ответе.
- **Kill-критерий не считается записанным без наблюдателя** — того, что напомнит о нём в срок (хук на старте сессии, календарь, задача).
- Сработал kill-критерий → урок в память. Судим ПРОЦЕСС на момент решения, а не исход. Удачный образец → память → законное понижение уровня для таких же будущих решений.
- **Kill-критерии самого метода** (раз в месяц): «финалист = первый кандидат» чаще 70%; ноль гибридов за месяц; ноль повышений уровня по ходу; ноль сработавших kill-критериев. Любой сработал → разбор метода.

## Оркестровка (L3–4)

Помощники с чёткими заданиями; полные карточки — в файлах, в основной контекст — выжимки. Обезличивание вариантов, перемешивание порядка, слияние дублей — механически. Остановить линию может только оркестратор, с контрольной точкой после каждого этапа. Массовая работа — модель попроще; вердикты (суд, скептик, финал) — основная модель.
