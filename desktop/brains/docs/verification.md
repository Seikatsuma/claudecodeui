# Протокол проверки — как узнать, сделано или нет

Правило одной строкой: **проверяется не файл, а то, что видит человек в конечном результате.** Записанный код, зелёная сборка, свежий коммит, поиск по собранным файлам, «сервис активен» — признаки процесса, а не результата. В доказательства они не идут.

Каждый пункт задачи закрывается ровно одним из четырёх вердиктов:

| Вердикт | Когда ставится |
|---|---|
| **СДЕЛАНО** | проверка выполнена на конечном результате и дала ожидаемое |
| **СДЕЛАНО ЧАСТИЧНО** | работает, но есть замечания — перечислить каждое |
| **НЕ СДЕЛАНО** | проверка выполнена и показала, что результата нет |
| **НЕ ПРОВЕРЕНО** | проверить было нечем — написать, чем именно и что мешает |

«Готово», «должно работать» вердиктами не являются. Вердикт без доказательства = НЕ ПРОВЕРЕНО.

## Шаг 1. Чем доказываем — по типу правки

| Что меняли | Доказательство | Обязательные детали |
|---|---|---|
| Вид интерфейса | снимок элемента **до** и **после** на живом адресе | телефонная и десктопная ширина; снимок открыть и посмотреть глазами |
| Поведение (кнопка, форма, бот) | пройти сценарий как человек | начальное состояние → действие → конечный экран |
| Сервер, API | запрос и полный ответ | код и тело ответа; ожидаемое значение названо ДО запуска |
| Данные | число до и после | каким запросом считал, сколько строк затронуто |
| Фоновая задача | запись в журнале + результат её работы | время последнего успеха, а не «запущено» |
| Документ для людей | страницы в картинках + осмотр глазами | таблицы не разъехались, числа не разорваны |

## Шаг 2. Проверка на неровность (для всего видимого)

Работает ≠ выглядит правильно:
1. **Соседи не поехали** — снимок области целиком, а не только правленого куска.
2. **Границы** — самый длинный текст, самое большое число, пустое состояние.
3. **Узкий экран** — ничего не налезает и не обрезано.
4. **Консоль чистая** — ошибки и упавшие запросы идут в замечания.
5. **Осмотр глазами** — автопроверка ловит геометрию, но не ловит уродство.

Найденное на этом шаге — не «мелочь на потом», а замечание в вердикте.

## Шаг 3. Доставка до человека

«Выкачено» ≠ «человек это видит». Между ними кэш, старая версия приложения, долгоживущая сессия. Для правки, которую смотрит пользователь:
- в интерфейсе есть видимая метка версии — за секунду сверить, доехало ли;
- метка старая — разбираться в доставке, а не выкатывать повторно;
- пока правка не видна у пользователя, вердикт не СДЕЛАНО, а ЧАСТИЧНО.

## Шаг 4. Независимый проверяющий

Тот, кто делал, проверяет себя с натяжкой. Перед сдачей существенного результата отдельный помощник получает **исходную задачу пользователя дословно** (не пересказ) и доказательства, и отвечает по каждому пункту вердиктом плюс «что упущено». Его вердикт ниже моего — берётся его. Найденное доделывается ДО сдачи. Потолок — 3 круга.

Проверяющему запрещено верить словам: только снимки, выводы команд, ответы сервера. Пересказ снимка помощником доказательством не считается — смотреть самому.

## Шаг 5. Отчёт

В ответе пользователю — только проверенное: что сделано и чем это видно. Непроверенное так и называется, с причиной.
