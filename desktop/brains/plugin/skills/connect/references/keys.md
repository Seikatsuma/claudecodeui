# Ключи и токены: где взять, где хранить, как пользоваться

Ключ (API key, токен бота, пароль приложения) — это доступ к деньгам и данным человека. Обращаться как с ключами от квартиры.

## Где взять — вести по шагам, страницу открыть самому
Типовые: Telegram-бот — в Telegram написать @BotFather → `/newbot` → имя → он пришлёт токен. OpenAI — platform.openai.com/api-keys. Google Gemini — aistudio.google.com/apikey. Остальные — найти «<сервис> API key» (навык `find-first`) и дать 3–5 шагов с названиями кнопок. Платный ли ключ — сказать заранее.

## Как принять
Человек вставляет ключ в чат — это нормально (переписка хранится только на его компьютере). Дальше:
- в ответах ключ целиком не повторять — только последние 4 знака: «ключ …7fQa сохранил»;
- сразу проверить ключ безвредным запросом (Telegram — `getMe`, OpenAI — список моделей) и сказать результат;
- сохранить в хранилище ниже и дальше брать оттуда, а не из переписки.

## Где хранить
**Никогда** — в папке проекта, в коде, в `.mcp.json`, в git, в облачной папке (Диск, Dropbox), в письмах и сообщениях.

**Mac — «Связка ключей»** (встроена в систему, ключ шифруется):
```
security add-generic-password -U -a "$USER" -s "claudeui.<имя>" -w '<ключ>'      # сохранить / заменить
security find-generic-password -a "$USER" -s "claudeui.<имя>" -w                  # прочитать (в скрипте)
```
Mac может показать окно «разрешить доступ к связке ключей» — сказать человеку заранее: «нажмите «Разрешить всегда»».

**Windows — файл в личной папке пользователя** `%USERPROFILE%\.claudeui\keys.env`, строки `ИМЯ=значение`. Создать папку, дописать строку, в скрипте читать этот файл.

Список сохранённого (без значений) держи в `~/.claudeui/keys-list.txt`: имя, для чего, дата — чтобы в следующем чате знать, что ключ уже есть, и не просить снова.

## Как пользоваться
- **Подключение (MCP) с ключом** — `claude mcp add --scope user --env ИМЯ=<ключ> --transport stdio <имя> -- <команда>`: ключ ляжет в личные настройки Claude (`~/.claude.json`), не в проект. Область `project` для ключей не использовать — она попадает в папку проекта.
- **Скрипт** — читает ключ из хранилища при запуске (Mac — `security find-generic-password … -w`, Windows — `keys.env`); в сам файл скрипта ключ не вписывать.

## Если ключ утёк
Попал в общий доступ (git, чат с людьми, скриншот) — сказать прямо и провести человека по отзыву ключа в кабинете сервиса («Revoke» / «Удалить» → создать новый), затем заменить в хранилище.
