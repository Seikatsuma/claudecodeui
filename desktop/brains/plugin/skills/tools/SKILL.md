# Инструменты: фото, видео, таблицы, документы — на компьютере человека

Человек терминалом не пользуется: всё ставишь и запускаешь ты сам, ему показываешь результат (таблицу, папку, кадры). На его Mac или Windows **по умолчанию нет** Python-библиотек, Node и ffmpeg — это нормально, они ставятся за минуту **в домашнюю папку, без пароля администратора**.

Папку, которую назвал человек, ищи по порядку: открытая в чате папка → Рабочий стол, Загрузки, Документы, Изображения (`~/Desktop`, `~/Downloads`, `~/Documents`, `~/Pictures`) → облачные папки (`~/Library/CloudStorage` на Mac). По всему диску не ищи.

Готовые программы навыка лежат в `scripts/` рядом с этим файлом (путь к папке навыка тебе показан при его загрузке). Сначала бери их, свои пиши, только если их не хватает.

## Установка инструментов (один раз на компьютер)

**uv — Python и любые библиотеки без администратора.** Проверь `uv --version`; нет — поставь:
- Mac: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
Ставится в `~/.local/bin` (Windows — `%USERPROFILE%\.local\bin`); программа уже ищет там, в новых командах `uv` будет виден сразу. Python отдельно ставить не нужно — `uv` скачает его сам.

Дальше Python-программы запускаются так: `uv run скрипт.py` (библиотеки из шапки `# /// script` ставятся сами) или `uv run --with openpyxl --with pandas python скрипт.py`. `pip install` в систему и `sudo` не используй.

**Node (для подключений через `npx`)** — только если нужен. Без администратора — в `~/.claudeui/node`:
- Mac: версию LTS взять из `https://nodejs.org/dist/index.json` (первая запись с `"lts"` не false), скачать `node-<версия>-darwin-arm64.tar.gz` (Intel — `darwin-x64`; процессор — `uname -m`), распаковать в `~/.claudeui/node` так, чтобы был `~/.claudeui/node/bin/node`.
- Windows: `node-<версия>-win-x64.zip` → распаковать в `%USERPROFILE%\.claudeui\node` (там `node.exe`, `npx.cmd`).
Программа уже ищет в этих папках.

**Mac попросил «установить инструменты разработчика»** (окно при `python3`, `git`) — это установка Apple на 5–15 минут, делает человек кнопкой «Установить». Но через `uv` она обычно не нужна — сначала `uv`.

## Фото
- **Сведения о всех фото папки** — дата, место съёмки (координаты), камера, а с `--places` ещё и адрес (город, улица) по OpenStreetMap:
  `uv run <папка навыка>/scripts/photos_info.py "<папка с фото>" --places`
  Пишет `фото-сведения.csv` (открывается в Excel/Numbers) и печатает, сколько фото с местом и без. HEIC с iPhone читает. Адреса — не чаще 1 в секунду: 1000 фото из разных мест ≈ 20 минут, скажи об этом заранее; одинаковые места берутся из запомненного.
- **Разложить по папкам** (по городам, датам, поездкам) — по этой таблице **сразу копируй** в подпапки рядом (копия ничего не портит — спрашивать не нужно), исходные имена сохраняй; в ответе — итог («Москва — 120 фото, Казань — 45, без места — 30») и открытая папка (`open` / `start`). **Перенести** оригиналы вместо копий или убрать их — только после «да».
- **Что на фото** — открой снимок инструментом Read и посмотри сам (большие HEIC сначала уменьши в JPEG: `uv run --with pillow --with pillow-heif python …`, на Mac можно `sips -s format jpeg -Z 1600 in.heic --out out.jpg`). Сотни фото глазами — выборочно или по партиям, помощникам поручать можно.
- Фото без места съёмки (скриншоты, пересланные в мессенджерах — там место стирается) — сказать честно, место по ним не восстановить; можно угадать по содержимому, пометив как догадку.

## Видео
- **Посмотреть видео:** `uv run <папка навыка>/scripts/video_frames.py "<видео>" --frames 8` — вынимает кадры равномерно по длине, печатает длительность, дату и место съёмки (если телефон их записал). Потом открой кадры инструментом Read. Длинное видео — больше кадров (`--frames 20`) или по частям.
- **Звук в текст:** тот же скрипт с `--audio` даёт `audio.wav`; расшифровка на компьютере — `uv run --with faster-whisper python …` (модель small — скачает ~500 МБ один раз, час записи — 10–30 минут на обычном ноутбуке; скажи об этом заранее).
- **Резать, склеивать, сжимать** — сам ffmpeg: путь к нему `uv run --with imageio-ffmpeg python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())"`. Результат — новым файлом рядом, исходник не трогать.

## Таблицы
- **Excel `.xlsx`** — `uv run --with openpyxl python …` (оформление: жирная шапка, ширина колонок, закреплённая первая строка, формат чисел и дат). Большие данные — `--with pandas`.
- **CSV** — для обмена; для Excel в России — разделитель `;` и кодировка `utf-8-sig`, иначе русские буквы и колонки поедут.
- **Таблица Google** — собрать `.xlsx` и загрузить через подключение Google Drive (навык `connect`, `references/google.md`).
- После создания — открой таблицу человеку (`open "файл.xlsx"` / `start "" "файл.xlsx"`) и прочитай её обратно сам: числа, шапка, пустые строки.

## Документы
- Word `.docx` — `uv run --with python-docx python …`; PDF читать — `--with pypdf` (скан без текста — открыть страницы как картинки Read'ом); PDF собрать — `--with reportlab` или сначала `.docx`.
- Документ людям — перед сдачей открыть и посмотреть, как он выглядит.

## Файлы пачкой
Переименовать, разложить, найти дубликаты — сначала список «было → станет» человеку, потом делать; копировать/перемещать, а не удалять. Удаление — только по правилам мозгов (явное «да»).
