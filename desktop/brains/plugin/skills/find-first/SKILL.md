# find-first — сначала найди готовое

Правило: не придумывать, а находить; брать лучшее; источники — официальные и эксперты, не форумы.
**Не пропускать ради экономии:** найденное окупается меньшим числом переделок. Дорого не поиск, а помощники для поиска и выгрузка страниц целиком.

## Дёшево по умолчанию (любая задача)
1. **Своё:** поиск по проекту, его документация, память — решение уже есть → взять.
2. **Веб-поиск** 3–6 запросов (разные формулировки, и по-английски) → **3–5 лучших страниц с конкретным вопросом** (выжимка, а не страница целиком).
3. **GitHub** — для кода и готовых проектов: поиск репозиториев и обсуждений ошибок (issues).
4. Глубина по размеру: один факт — 1–2 официальные страницы; новый проект, дизайн, текст — 5+ аналогов.

## Иерархия источников
- Код: документация и журнал изменений → issues и релизы авторов → инженерные блоги → Stack Overflow.
- Учёт, налоги, право: официальные государственные сайты и тексты законов → справочно-правовые системы → профильная пресса; первоисточник недоступен — статья закона + дата + «сверить со специалистом».
- Дизайн интерфейсов: Apple HIG, Material, WCAG → Nielsen Norman Group.
- Практики ИИ: документация вендоров → исследования с авторами (arXiv, конференции).
- Форумы, Reddit, перепечатки — только наводка на первоисточник; на одной наводке решение не держится.

## Оценка (в своём размышлении)
- Код: живость проекта, лицензия (MIT/Apache/BSD — да; GPL/AGPL — решает пользователь; без лицензии — только идея).
- Тексты: свежесть, автор, есть ли первоисточник, цель автора (обучить или продать).

## Дорогой режим — только деньги, право, налоги, платное решение
Найти точную цитату на странице первоисточника. Не найдена — утверждение убрать или понизить до наводки.

## Запись и как видит пользователь
- В проекте — строка в план или документацию: «Решение — источник (официальный / эксперт / наводка) — что взято — что отвергнуто и почему».
- В ответе простыми словами: «по документации X», при важности — 1–3 ссылки.
- Не нашёл — «искал там-то; готового нет, делаю своё, потому что …».
